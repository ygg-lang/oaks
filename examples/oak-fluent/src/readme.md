# Oak Fluent

## Overview

Oak Fluent is a Fluent internationalization syntax parser built on the Oak framework, providing high-performance, incremental parsing for Fluent translation files.

## Features

- **High-performance parsing**: Leverages Oak's optimized lexing and parsing infrastructure
- **Incremental updates**: Re-parses only modified sections for real-time editing
- **Complete AST support**: Full representation of Fluent syntax including messages, attributes, terms, and select expressions
- **Lossless syntax tree**: Retains all whitespace and comments for round-trip processing
- **Translation support**: Built-in translator for message lookup and interpolation
